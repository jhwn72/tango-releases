# Tango

One mouse, keyboard and clipboard across your Mac and PC.

Download the latest version from [Releases](https://github.com/jhwn72/tango-releases/releases/latest):

- **Mac:** `Tango_…_mac.dmg`. Open it and drag Tango to Applications. The first time, right-click Tango and choose **Open**, then **Open** again (Tango isn't signed by Apple yet). Allow Tango under **Accessibility** when it asks.
- **Windows:** `Tango_…_windows-setup.exe`. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**. Allow Tango on **private networks** when the firewall asks.

Open Tango on both computers. The first time, one shows a 6-digit code to type on the other. Tango keeps itself up to date after that.
